# DSH 用量统计设计

范围：整个 DSH 全部模型和服务商；今日、本周（周一始）、本月、累计 Token，日/周/月趋势，服务商与模型筛选，模型生成速度 Token/s。北京时间；Token 按实际 usage（包含缓存）累计；速度仅有效流式计时样本按总输出/总耗时计算；缺失计量或速度明确显示覆盖情况。只读现有会话日志；仅缓存聚合数字与必要文件指纹，不缓存正文或凭据。读取最高版本日志，同会话目录去重；多帧 zstd/未压缩日志、坏行与未完成尾帧容错；增量扫描不阻塞模型调用。

方案：参考 MIT dsh-dashboard 的帧解析和速度口径，独立精简模块，不依赖原插件，也不移植费用、工具/技能、质量、编排等功能。沿用现有样式，在插件详情/设置中增加独立用量统计区域。
