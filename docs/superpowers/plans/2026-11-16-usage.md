# DSH Usage Implementation Plan

**Goal:** 整个 DSH 的服务商/模型、Token 周期与生成速度统计。
**Architecture:** workbuddy-usage.js 只读增量扫描和纯聚合；workbuddy-usage-web.js 提供本机受保护路由与 storageDomain 缓存；client.js 独立图表/筛选区域。
**Tech Stack:** Node.js 原生 zstd/fs，DSH storageDomain，DOM/CSS/SVG，无新增运行时依赖。
**Spec:** ../specs/2026-11-16-usage-design.md

## Global Constraints
全 DSH、北京时间、只读日志、无正文/密钥缓存、保留现有账号和调用链、不移植其他功能。
## Review Focus
跨日/跨年周、缓存不重复、同名模型跨服务商、损坏/活跃日志、缺失计量/速度、同会话重复路径、并发刷新、卸载中断。

- [x] 用真实 68 个会话进行只读扫描，校验 totals 与上游参考结果，验证重复扫描不会累加。
